常见问题

常见问题，直接回答。

费用是多少？ +

启动时预付 $250，网站制作完成并经您确认通过后再付 $250，之后每月 $39 维护费（含托管、更新与修改）。首笔 $250 在您提交需求后，直接在本页面支付。

什么时候付哪笔款？ +

首笔 $250 在您提交需求后，立即在本页面支付，我们随即开始制作。第二笔 $250 要等您看过成品网站并确认通过后才支付。每月 $39 的维护费在网站确认通过并上线后开始。我们会用 info@brightfrontdesign.com 把成品网站发给您。

每月 $39 包含什么？ +

包含托管、保障网站安全并保持最新，以及您提出的各类修改，比如新的营业时间、新菜单或新照片。按月付费，没有合同，可随时取消。

我需要自己提供照片或文字吗？ +

刚开始用手机拍的照片就够了。告诉我们您做什么生意，把手头有的素材发给我们，我们会整理成清晰美观的页面。之后您也可以随时补充或替换。

手机上能正常使用吗？ +

可以。我们制作的每个网站都适配手机，并且优先在小屏幕上测试，因为大多数本地顾客正是通过手机找到您的。

适合哪些人？ +

咖啡店、美发沙龙、烘焙店、餐车、本地小店等小型独立商家，以及所有希望拥有一个简洁专业的网站、又不想自己动手的人。

需要多长时间？ +

收到照片和资料后，我们争取在约 3 个工作日内通过邮件发送第一版。之后取决于您查看和反馈修改的速度。

确认之前可以要求修改吗？ +

可以，这正是“确认”的意义。请用手机查看成品网站，告诉我们想调整的地方。您满意之后才支付第二笔 $250。

文字由谁来写？ +

由我们来写。您只需发几行要点，比如卖什么、店的特色、主要顾客是谁，我们会整理成清楚易读的文字。

没有 Logo 可以吗？ +

完全没问题。我们会用与网站风格相配的字体呈现店名，之后有了 Logo 也可以替换。

需要自己的域名吗？ +

如果已有域名，请在提交需求时告诉我们。如果想注册新域名，可以问我们如何设置。域名每年的注册费与我们的价格分开计算。

网站可以接受预约或在线点餐吗？ +

我们可以链接到您正在使用的预约或点餐服务，顾客一点即可跳转。这些服务有各自的费用。在网站上直接收款不包含在本方案中。

如何付款？ +

通过 PayPal 付款，PayPal 结账页面也可使用银行卡。首笔 $250 在提交需求后于本页支付；第二笔 $250 的付款通知会随成品网站一起发给您。

上线后如何申请更新？ +

把修改内容以及新照片或文件发到 info@brightfrontdesign.com 即可。修改包含在每月 $39 中。

有合同期限吗？ +

没有。维护按月付费，可随时取消。

做了网站就能排到 Google 前面吗？ +

没有人能诚实地保证排名。把营业时间、服务和地址以文字写在网站上，能让搜索引擎获得更多信息，也和完善的 Google 商家资料相辅相成。我们会设置清楚的标题和描述，但不承诺排名。

有 Instagram 还需要网站吗？ +

Instagram 很适合展示新作品和新品。网站则为所有人（无论是否使用 App）提供一个查看营业时间、价格和地址的可靠地方。
